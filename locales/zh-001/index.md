# 敏捷 ITIL 指标

**衡量敏捷 IT 服务，而不扭曲工作本身。**

一本关于如何做好敏捷 IT 服务管理度量的实用之书：12 个部分、88 个主题。每个指标都写明它可能被操纵的方式，以及能够发现这种操纵的护栏。指标描述团队、服务和系统，绝不用来给个人排名。
